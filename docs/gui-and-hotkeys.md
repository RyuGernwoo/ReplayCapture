# GUI·단축키 사용자 가이드 👤

이 문서는 배포된 ReplayCapture를 사용하는 일반 사용자를 위한 안내입니다. 프로그램 개발이나 빌드 과정은 [개발자 문서](architecture.md)에서 확인할 수 있습니다.

## 1. 실행과 첫 설정 🚀

1. 배포받은 ZIP 파일의 압축을 풉니다.
2. <code>ReplayCapture.exe</code>를 실행합니다.
3. **설정** 탭에서 녹화할 **모니터**와 **시스템 오디오 출력 장치**를 선택하고 **설정 적용**을 누릅니다.
4. 저장 폴더와 시간을 확인한 뒤 **녹화** 탭에서 **녹화 시작**을 누릅니다.

> 관리자 권한은 필요하지 않습니다. 처음 실행할 때 Windows가 게시자 경고를 표시할 수 있으며, 이는 현재 배포 파일에 코드 서명이 적용되지 않았기 때문입니다.

## 화면 구성 🧭

고정 크기 창의 왼쪽 메뉴로 화면을 전환합니다. 현재 선택한 메뉴 하나만 파란색으로 표시됩니다. 기능은 박스로 구분되며, 전체 창을 스크롤할 필요가 없습니다. 저장 작업 목록과 진단 내용은 각 영역 안에서 스크롤할 수 있습니다. 최소화와 창 이동은 가능합니다.

기준 본문 크기는 960×650이며 Windows 배율을 반영합니다. 작업 영역이 작으면 화면에 맞춰 배율을 조정합니다. Pretendard 글꼴을 내장하여 별도 설치 없이 표시합니다.

| 탭 | 할 수 있는 일 |
|---|---|
| **녹화** | 상태와 확보 시간 확인, 녹화 시작·중지·최근 기록 저장. 녹화 중에는 중지 버튼이 빨간색으로 표시 |
| **설정** | 모니터·오디오·보관 시간·저장 폴더·화질·메모리·알림·자동 실행 설정 |
| **단축키** | 전역 저장 단축키 변경·기본값 복원·입력 테스트 |
| **저장 작업** | 요청별 상태와 실제 길이 확인, 완성 영상 열기, 폴더에서 보기, 작업 취소 |
| **도움말·진단** | 문제 해결 안내, 현재 장치·녹화 상태 확인, 진단 복사·파일 저장 |
| **정보** | 개발자 연락처·버전·저작권·사용권 계약·글꼴 라이선스 확인 |

## 2. 최근 기록 저장 💾

녹화 중에는 다음 세 방법을 사용할 수 있습니다.

| 방법 | 동작 |
|---|---|
| **최근 기록 저장** 버튼 | 메인 화면의 **저장 길이**만큼 저장 |
| 전역 단축키 | 기본 저장 시간만큼 저장. 기본값은 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>F9</kbd> |
| 트레이 메뉴 | **최근 기록 저장**을 선택하면 기본 저장 시간만큼 저장 |

저장 작업 중에도 캡처는 계속됩니다. 여러 번 연속 저장하면 각 요청이 별도 MP4 파일로 처리됩니다.

~~~mermaid
sequenceDiagram
    participant U as 사용자
    participant R as ReplayCapture
    participant M as 메모리 버퍼
    participant F as MP4 파일
    R->>M: 화면·시스템 소리를 계속 보관
    U->>R: 버튼 또는 단축키 입력
    R->>M: 요청 구간 복사
    R->>F: H.264 + AAC로 저장
    R-->>U: 완료 알림
~~~

## 3. 시간 설정 이해하기 ⏱️

| 설정 | 적용되는 조작 | 설명 |
|---|---|---|
| **보관 시간** | 전체 캡처 | 메모리에 남겨 둘 최근 기록의 최대 길이 |
| **기본 저장 시간** | 단축키·트레이 | 저장 명령을 내렸을 때 기본으로 내보낼 길이 |
| **저장 길이** | GUI 버튼 | 이번 버튼 클릭에만 적용할 길이 |

예를 들어 보관 시간 120초, 기본 저장 시간 60초, 저장 길이 30초라면 메모리에는 최대 2분을 유지하고, 단축키는 최근 1분을, GUI 버튼은 최근 30초를 저장합니다.

> **기본 저장 시간과 저장 길이은 보관 시간 이하여야 합니다.** 녹화를 시작한 지 얼마 되지 않았다면 확보된 분량만 저장됩니다. **전체 분량이 찰 때까지 저장 금지** 옵션을 켜면 설정한 시간이 채워진 뒤에만 저장할 수 있습니다.

## 4. 단축키 변경 ⌨️

1. **단축키** 탭을 엽니다.
2. 새 키 조합을 입력합니다.
3. **적용**을 누릅니다.
4. 성공 안내를 확인한 뒤 다른 창에서도 단축키가 작동하는지 확인합니다.

이미 다른 프로그램이 사용하는 조합이면 등록에 실패하며 기존 단축키가 유지됩니다. <code>Ctrl</code>·<code>Alt</code>·<code>Shift</code>와 일반 키를 조합하세요. 단축키 화면에서 테스트하는 동안에는 실제 영상을 저장하지 않습니다.

## 5. 화질과 메모리 설정 🎛️

**설정 → 고급 설정**에서 화질과 자원을 조절합니다. **기본 설정** 버튼으로 돌아올 수 있습니다. 기본 설정은 화면과 소리, 기록과 저장, 일반 항목으로 구분되어 있습니다. 잘못된 값은 화면 하단에 이유가 표시되며 해당 입력칸으로 이동합니다.

편집한 값은 **설정 적용**을 눌러야 저장됩니다. 화면을 이동해도 편집 중인 값은 유지되며, **변경 되돌리기**를 누르면 현재 적용된 값으로 복원됩니다.

| 설정 | 높이면 생기는 변화 |
|---|---|
| 해상도·프레임률 | 움직임과 글자가 선명해지지만 메모리와 처리량이 증가 |
| 영상 비트레이트 | 화질이 좋아지지만 저장 파일 크기가 증가 |
| 최근 기록 메모리 한도 | 압축 기록의 보관 한도. 부족하면 오래된 기록부터 제거 |
| 녹화·저장 메모리 예산 | 저장 작업의 참조와 예약량까지 고려한 예산. 부족하면 추가 저장을 거절할 수 있음 |

총 예산은 전체 프로그램 메모리의 절대 상한을 의미하지 않습니다.

설정을 적용하는 동안 녹화가 실행 중이면 캡처가 다시 시작될 수 있습니다. 이때 아직 저장하지 않은 버퍼는 초기화되므로 필요한 구간을 먼저 저장하세요.

## 6. 녹화 중지, 트레이, 종료 🧰

| 조작 | 결과 |
|---|---|
| **다시 시작** | 빈 버퍼에서 캡처를 다시 시작 |
| **녹화 중지** | 현재 버퍼를 정리하고 녹화를 중지 |
| 창의 <code>X</code> | 앱을 종료하지 않고 트레이로 숨김 |
| 트레이 아이콘 클릭 | 메인 창 다시 표시 |
| 왼쪽 메뉴 또는 트레이 → **종료** | 캡처를 정리하고 프로그램 완전 종료 |

화면 잠금, 절전에 들어가면 보호를 위해 버퍼를 비웁니다. 다시 시작하거나 잠금이 해제되면 빈 버퍼에서 기록을 새로 쌓습니다. 소리 연결에 실패하면 항상 영상만 녹화하며 원인은 도움말·진단에서 확인할 수 있습니다.

## 7. 파일과 개인정보 🔒

- 영상은 선택한 로컬 폴더에 MP4로 저장됩니다.
- 설정도 로컬에 저장되며 외부 서버로 업로드하지 않습니다.
- 시스템 출력 소리가 영상에 포함될 수 있으므로 공유 전에 민감한 대화나 알림음이 들어갔는지 확인하세요.
- 손상된 저장을 막기 위해 외장 드라이브를 분리하기 전에 진행 중인 저장이 끝났는지 확인하세요.

문제가 생기면 [문제 해결 가이드](troubleshooting.md)를 확인하세요.
