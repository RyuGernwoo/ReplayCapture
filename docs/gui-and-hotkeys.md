# ReplayCapture 사용 안내

## 실행과 녹화

1. 배포 ZIP을 쓰기 가능한 로컬 폴더에 풉니다.
2. `ReplayCapture.exe`를 실행합니다. 관리자 권한은 필요하지 않습니다.
3. **설정**에서 모니터, 소리 장치, 보관 시간, 저장 폴더를 확인하고 **설정 적용**을 누릅니다.
4. **녹화 → 녹화 시작**을 누릅니다. 보관된 시간이 늘어나면 최근 기록을 저장할 수 있습니다.

설치 직후 기본값은 1080p30, 영상 8Mbps, 시스템 소리 포함, 최근 60초입니다. 마이크 입력은 이번 버전에 포함되지 않습니다. 시스템 소리는 선택한 출력 장치로 재생되는 소리입니다.

## 최근 기록 저장

- GUI: **녹화** 화면의 이번 저장 길이를 정하고 **최근 N초 저장**을 누릅니다.
- 단축키: 기본 `Ctrl+Shift+F9`. 다른 앱에 포커스가 있거나 창이 트레이에 숨겨져 있어도 동작합니다.
- 트레이: 아이콘을 오른쪽 클릭하고 **최근 N초 저장**을 선택합니다.

GUI의 이번 저장 길이는 이번 버튼 저장에만 적용됩니다. 단축키와 트레이는 설정의 **기본 저장 시간**을 사용합니다. 저장 위치는 미리 설정한 폴더이며 매번 대화상자가 뜨지 않습니다. 저장하는 동안에도 녹화가 계속됩니다.

저장 결과는 **저장 작업** 탭에서 확인합니다. 완료된 파일은 **영상 열기**, **폴더에서 보기**로 열 수 있습니다. 대기·진행 작업은 **작업 취소**로 취소할 수 있습니다. 작업 목록은 현재 앱 실행 세션의 최근 100개입니다. 완료 영상은 자동 삭제하지 않습니다.

빠른 저장은 재인코딩 없이 직전 키프레임부터 MP4를 만듭니다. 따라서 최근 60초 요청이 약 60~61초 영상이 될 수 있습니다. 처음 시작했거나 버퍼를 비운 직후에는 실제 쌓인 길이만 저장합니다. **전체 길이가 쌓인 경우만 저장**을 선택하면 기록 부족 시 저장하지 않습니다.

## 단축키 변경

1. **단축키** 탭에서 키 입력칸을 선택합니다.
2. 원하는 Ctrl/Alt/Shift와 키 조합을 누릅니다.
3. **단축키 적용**을 누릅니다. 충돌하면 기존 키가 유지됩니다.
4. **단축키 테스트**를 누르고 적용된 키를 눌러 입력 수신을 확인합니다.

단축키 설정 화면이 열려 있는 동안에는 실제 저장을 억제합니다. 다른 탭으로 이동하거나 창을 트레이에 숨기면 일반 저장 동작으로 돌아갑니다. 키를 계속 누르고 있어도 반복 저장하지 않습니다. 변경한 키는 재실행 후에도 유지됩니다.

## 시간·화질·메모리

설정 화면에서 보관 시간, 기본 저장 시간, 출력 크기, FPS, 비트레이트, 압축 메모리 상한, 총 예산 및 저장 대기 수를 변경합니다. 적용하기 전 오류를 검사합니다. 불가능한 시간·메모리 조합은 적용하지 않습니다.

기본 8Mbps에서 60초의 압축 데이터는 약 61MB입니다. 여러 저장 작업이 동시에 이전 기록을 참조하면 추가 메모리가 필요합니다. 공간이 부족하면 새 저장이 실패하며 이유가 작업 화면에 표시됩니다. 이 경우 기존 저장이 끝날 때까지 기다리거나 총 예산을 늘리십시오.

**설정 적용 시 녹화 중인 미저장 버퍼는 초기화됩니다.** 기존에 접수한 저장 작업은 유지됩니다. 더 긴 시간으로 바꾸더라도 과거 기록을 소급해서 만들 수 없습니다.

## 중지·창 닫기·종료

- **일시정지**: 새 수집을 멈추고 미저장 버퍼를 비웁니다. **재개**하면 새 기록을 쌓습니다.
- **녹화 중지**: 녹화와 버퍼를 정리하고 앱은 열어 둡니다.
- **버퍼 비우기**: 미저장 기록을 비우고 녹화 중이면 새 기록을 계속 쌓습니다.
- 창의 **X**: 트레이로 숨깁니다. 녹화 중이면 계속 녹화합니다.
- **앱 종료**: 진행 중 저장에 최대 10초의 완료 기회를 준 뒤 종료합니다.

잠금·절전 때는 버퍼를 비우고, 이전에 녹화 중이었다면 복귀 시 새 기록을 시작합니다. 장치 오류는 최대 3회 재시도하며 계속 실패하면 **진단 → 장치 다시 연결** 또는 설정에서 장치를 다시 선택하십시오.

## 자동 실행과 데이터

자동 실행은 기본으로 꺼져 있습니다. 설정에서 활성화하면 Windows 로그인 시 앱이 열립니다. 녹화는 GUI의 **녹화 시작**으로 시작합니다. 설정은 사용자 LocalAppData의 ReplayCapture 폴더에 저장됩니다. 앱은 화면·소리를 외부로 전송하지 않습니다.

프로그램을 제거하려면 자동 실행을 끄고 앱을 종료한 뒤 압축을 푼 폴더를 삭제하십시오. 설정을 초기화하려면 GUI의 기본값 불러오기 후 설정 적용을 사용하십시오. 단축키 기본값은 단축키 탭에서 별도로 적용합니다.
