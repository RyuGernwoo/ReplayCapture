# 문제 해결 가이드 🧯

먼저 메인 화면의 상태 문구와 알림을 확인하세요. 아래 방법으로 해결되지 않으면 로그와 재현 순서를 함께 첨부해 저장소에 문제를 등록할 수 있습니다.

## 👤 일반 사용자 문제 해결

| 증상 | 확인할 내용 | 해결 방법 |
|---|---|---|
| 녹화가 시작되지 않음 | 모니터 선택, Windows 캡처 권한, 원격 접속 여부 | 로컬 세션에서 모니터를 다시 선택하고 앱을 다시 실행합니다. |
| 영상에 소리가 없음 | 선택한 출력 장치와 실제 재생 장치가 같은지 | 소리가 재생되는 스피커·헤드셋을 다시 선택한 뒤 녹화를 재시작합니다. |
| 단축키가 작동하지 않음 | 다른 앱이 같은 조합을 쓰는지 | **단축키** 탭에서 다른 조합을 등록합니다. |
| 저장 버튼을 눌러도 거절됨 | 녹화 시작 직후인지, 전체 분량 대기 옵션이 켜졌는지 | 설정 시간이 찰 때까지 기다리거나 대기 옵션을 끕니다. |
| 저장 영상이 요청 시간보다 약간 김 | 앞쪽 키프레임부터 저장했는지 | 빠른 저장 방식의 정상 동작입니다. 필요한 경우 재생 앱에서 잘라냅니다. |
| 저장 영상이 요청 시간보다 짧음 | 현재 버퍼에 충분한 기록이 있는지 | 녹화를 더 유지한 뒤 다시 저장합니다. |
| 화면이 검거나 일부 영상이 빠짐 | 보호 콘텐츠·보안 화면인지 | 일반 바탕 화면에서 확인합니다. 보호된 콘텐츠는 녹화되지 않을 수 있습니다. |
| 메모리 경고가 자주 나타남 | 보관 시간, 해상도, 프레임률이 높은지 | 보관 시간 또는 품질을 낮춥니다. |
| 저장 폴더에 파일이 없음 | 폴더 권한, 남은 용량, 외장 드라이브 연결 | 쓰기 가능한 로컬 폴더로 변경하고 여유 공간을 확보합니다. |
| 창을 닫았는데 프로그램이 계속 실행됨 | 트레이 아이콘이 있는지 | 정상 동작입니다. 트레이 우클릭 → **앱 종료**로 종료합니다. |

## 빠른 점검 순서 🔍

1. 트레이 또는 메인 화면에서 녹화 상태를 확인합니다.
2. 모니터와 시스템 오디오 장치를 다시 선택합니다.
3. 저장 폴더의 쓰기 권한과 남은 공간을 확인합니다.
4. 설정을 적용한 뒤 녹화를 재시작합니다.
5. 계속 실패하면 앱을 완전히 종료한 뒤 다시 실행합니다.

> 화면 잠금, 절전, 장치 변경, 녹화 설정 적용 뒤에는 버퍼가 초기화될 수 있습니다. 중요한 구간은 먼저 저장하세요.

## 🛠️ 외부 개발자 진단

문제를 보고할 때 다음 정보를 함께 남기면 재현이 쉬워집니다.

- ReplayCapture 버전과 실행 파일 출처
- Windows 버전, GPU 및 드라이버 버전
- 모니터 해상도·배율·HDR 사용 여부
- 선택한 오디오 장치와 연결 방식
- 보관 시간, 해상도, 프레임률, 비트레이트
- 오류가 발생한 정확한 조작 순서
- 생성된 MP4의 재생 가능 여부와 파일 크기
- 가능하면 민감한 정보를 제거한 화면 또는 로그

개발 빌드에서는 다음 순서로 기본 회귀 여부를 확인합니다.

~~~powershell
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
~~~

지원 범위와 아직 수행하지 않은 환경 검증은 [검증 보고서](validation-report.md)를 참고하세요.
