# 문제 해결

| 현상 | 확인·조치 |
|---|---|
| 저장 버튼이 비활성화됨 | 녹화를 시작하고 첫 키프레임이 쌓일 때까지 기다리십시오. 전체 길이 필수 설정도 확인하십시오. |
| 소리가 없거나 녹화가 실패함 | 선택한 출력 장치로 소리가 재생되는지 확인하십시오. 다중 채널 장치는 Windows에서 스테레오로 설정하십시오. |
| HDR 지원 오류 | 해당 모니터의 Windows HDR 설정을 끈 뒤 시작하십시오. |
| 단축키가 등록되지 않음 | 다른 앱에서 사용하지 않는 Ctrl/Alt/Shift 조합으로 변경하십시오. GUI 저장 버튼은 계속 사용할 수 있습니다. |
| 단축키 테스트 중 영상이 안 만들어짐 | 테스트와 키 설정 화면에서는 저장을 억제합니다. 녹화 탭으로 이동하거나 트레이로 숨기십시오. |
| 길이가 요청보다 조금 김 | 키프레임부터 시작하는 빠른 저장 방식의 특성입니다. |
| 길이가 요청보다 짧음 | 프로그램 시작·재개·설정 적용 후 보관된 길이를 확인하십시오. |
| 저장 메모리가 부족함 | 진행 작업 완료 후 다시 저장하거나 총 메모리 예산을 늘리십시오. |
| 저장 실패 | 폴더 권한, 디스크 여유 공간과 작업 화면의 상세 메시지를 확인하십시오. |
| 해상도·장치 변경 후 복구 중 | 자동 재연결을 기다리거나 진단의 장치 다시 연결을 사용하십시오. 지속되면 설정에서 대상을 다시 선택하십시오. |
| CPU 부하·누락이 높음 | 해상도·FPS를 낮추고 진단에서 하드웨어 인코더 선택 여부를 확인하십시오. |
| 창을 닫아도 녹화가 계속됨 | X는 트레이로 숨기기입니다. 명시적인 앱 종료를 사용하십시오. |

문제 보고에는 **진단 → 진단 파일 저장** 결과, Windows 버전, GPU·드라이버, 재현 단계를 첨부하십시오. 진단에 실제 화면·소리 데이터는 포함하지 않습니다.

보호 콘텐츠, 보안 데스크톱, 원격 데스크톱과 모든 GPU 조합의 캡처를 보장하지 않습니다. 메모리 기록은 프로세스 강제 종료 시 사라집니다. OS 페이지 파일·크래시 덤프에 데이터가 남지 않는다고 보장하지 않습니다.
