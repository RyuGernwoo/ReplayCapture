# ReplayCapture

Windows에서 모니터 화면과 시스템 소리의 최근 기록을 보관하고, GUI 버튼 또는 사용자 지정 키보드 단축키로 영상 파일을 저장하는 프로그램입니다.

## 현재 상태

현재는 **개발 계획 수립 단계**입니다. 프로그램 소스, 실행 파일, 설치 패키지는 아직 없으며 기능·성능 검증도 수행하지 않았습니다.

상세 요구사항, 구조, 구현 단계와 검증 기준은 [한국어 개발 계획서](WINDOWS_REPLAY_RECORDER_PLAN.ko.md)를 참고하십시오.

## 계획된 주요 기능

- 백그라운드에서 선택한 모니터 화면과 시스템 소리 캡처
- 최근 60초 기본 보관 및 사용자 지정 보관·저장 시간
- GUI 버튼과 사용자 지정 전역 단축키를 통한 최근 기록 저장
- 시작·일시정지·재개·중지·설정·저장 작업 관리 등 모든 기능의 GUI 조작
- 단축키 변경, 충돌 확인, 테스트 및 재시작 후 설정 유지
- H.264 영상과 AAC 오디오를 포함하는 MP4 저장
- 저장 중에도 녹화를 유지하는 압축 순환 버퍼

초기 빠른 저장 모드는 키프레임 경계 때문에 요청한 시간보다 약 1초 일찍 시작할 수 있습니다. 실제 저장 길이와 기록 부족 여부는 GUI에 표시하도록 계획되어 있습니다.

## 개발 방향

Windows 11 x64를 우선 검증 대상으로 하며 C++20, C++/WinRT, Windows.Graphics.Capture, WASAPI, Media Foundation 및 Win32 GUI를 사용할 계획입니다. 빌드 도구는 CMake·MSVC·Windows SDK를 사용하며 구체적인 버전과 빌드 방법은 구현 시 확정합니다.

먼저 화면·시스템 소리를 MP4로 기록하는 최소 실험을 수행한 뒤, 순환 버퍼와 GUI·단축키 저장 기능을 연결하고 복구·품질 검증·패키징을 진행합니다.
