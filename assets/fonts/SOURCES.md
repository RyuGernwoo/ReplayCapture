# Pretendard

ReplayCapture bundles unmodified Pretendard Regular and SemiBold 1.3.9 in its executable. Fonts are loaded privately for this process, without a system-wide installation.

- Project: https://github.com/orioncactus/pretendard
- Version: https://github.com/orioncactus/pretendard/tree/v1.3.9
- Original files: `packages/pretendard/dist/public/static/Pretendard-Regular.otf` and `Pretendard-SemiBold.otf`
- License: SIL Open Font License 1.1; the upstream copyright notice and full license are preserved in [OFL.txt](OFL.txt).

The repository retains the source font files for reproducible resource compilation. The application falls back to Malgun Gothic if the bundled fonts cannot be loaded.
